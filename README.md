# Spring Boot REST — Estudo

Este repositório é o meu **treino e estudo** do curso de **API REST com Spring Boot** da Udemy (instrutor Erudio). O código acompanha as aulas e pode conter experimentos, ajustes e decisões que não são de produção.

## Tecnologias

- Java 25
- Spring Boot 4.1.1
- Spring Web e Spring Data JPA (Hibernate)
- MySQL 8
- Flyway (migrations do banco)
- Dozer (conversão entre entidade e DTO)
- SLF4J / Logback
- Maven

## O que já foi praticado

- CRUD de `Person` com os verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`)
- Arquitetura em camadas (controller, service, repository)
- DTOs e versionamento de API (v1 e v2)
- Customização do JSON com Jackson (`@JsonProperty`, `@JsonPropertyOrder`)
- Migrations de banco com Flyway
- Logs com SLF4J

## Aviso

Projeto de aprendizado, sem compromisso de manutenção. Não use como base para produção.
